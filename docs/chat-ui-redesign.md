# 聊天界面重设计

以用户提供的聊天应用截图为视觉依据，不沿用旧前端设计 skill。

## 设计约定

- 主界面为两栏：浅灰会话列表 + 白色聊天区。桌面侧栏 300px，窄窗口 250px；手机上会话列表和聊天切换显示。
- 左侧顶部是 Raft 与创建入口、搜索框，接着是群聊和私聊。每项提供彩色头像、名称和最近公开消息摘要。底部保留工作台、模型设置和连接状态。
- 顶部仅一条会话标题栏。群聊使用叠放头像，成员数量为次要信息。详情默认关闭，通过信息按钮打开。
- Agent 消息在左侧，浅灰大圆角气泡；用户消息在右侧，黑色气泡。Agent 姓名使用角色色，时间降低对比度。正文 16px，行高 1.75。
- 头像使用原创双眼几何图形，按 Agent 在列表中的顺序分配橙、粉、青、紫四种颜色，同一角色在会话与消息中一致。
- 输入区为白色胶囊，使用真实的发送和群成员提及功能，不照搬参考图中当前产品不存在的语音、市场或附件功能。
- 设置、Skills、任务、审批、历史与日志保留原有能力，统一为中性色。工具活动默认折叠；必要时用户主动打开。
- 保留键盘操作、中文输入法、Markdown、窄屏代码横向滚动和错误反馈。

## SDK 核查与范围

2026-09-17 查阅官方 TypeScript API 参考：https://platform.claude.com/docs/en/agent-sdk/typescript 。实际安装与 package.json 锁定的 SDK 版本为 0.3.267。继续使用现有 SDK 消息、会话与运行记录接口；本次仅重新组织 React 展示与 CSS，不新增 Agent 循环、上下文或工具执行实现。

## 验证

运行 npm run check，使用本地隔离服务验证创建、私聊/群聊、搜索、提及、设置和上下文详情；用模拟消息截图核查桌面及窄屏布局，不调用付费模型。

## 验证结果

- `npm run check`：类型检查、66 项自动化测试与生产构建通过。
- `npm run smoke:ui`：创建、私聊、群聊、Markdown、提及、Skills、模型设置、群成员、窄屏通过。
- `npm run smoke:inspection` 与 `npm run smoke:context-ui`：详情侧栏、历史、日志、上下文隔离通过。
- `npx tsx tests/chat-design-smoke.ts`：搜索与空结果、按钮提及、默认关闭详情、390px 手机返回与切换通过。
- 使用隔离测试数据生成 `.raft/verification/chat-redesign-{desktop,narrow,mobile}.png`，已人工查看桌面、手机与设置弹窗截图。
